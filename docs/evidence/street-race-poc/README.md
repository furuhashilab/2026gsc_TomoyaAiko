# Street Race Visual PoC — Phase 1（札幌デモ・代表直線 1 区間）

確認日：2026-11-07。環境：macOS 27.0.1（Apple M4）、開発サーバー（Vite）、アプリ内ブラウザ（幅 981 px の描画領域）。コース：`sapporo-demo-circuit-001`（3,369 m、手動作成、OSM 由来のためコミットしていない）。

**架空のレース演出です。実際の道路幅・安全設備・道路封鎖計画を示すものではありません。** 公道でレースを開催できることや、FIA などの安全基準を満たすことは示しません。

## 1. 内容
既存の GIS ビューアに「レース演出」の切り替えを追加した。オンのときだけ、コースの **s = 290〜560 m（約 270 m、直線）** に次を表示する。
- 仮想のアスファルト路面（幅 9 m は表示用の仮の値）、白線、赤白の縁石
- コンクリートバリア（高さ 1.0 m、厚さ 0.6 m、路面の端から 0.5 m 外側）と、軽量なキャッチフェンス（地面から 3.5 m まで）
- 架空スポンサーの広告 4 枚（実在の企業名・ロゴ・公式グラフィックは使っていない。各パネルに「FICTIONAL SPONSOR」と表示）

オフのときは、既存の表示とまったく同じ。コース線・車両・カメラ・ミニマップの機能は変えていない。

**スタート・フィニッシュライン：** この区間はコースの s = 0 ではないため置いていない。正式なラインを置く場合は s = 0 の位置にする（今回は延期）。

## 2. 構成
| 場所 | 役割 |
|---|---|
| `config/presentation/sapporo-demo.json` | 配置の設定。位置はすべてコース上の距離 s で指定する（緯度経度の固定値は持たない）。`course_id` が一致するコースにだけ適用する |
| `web/src/presentation/config.ts` | 設定の検証（範囲、左右、色、高さ、広告がバリアの上にあるか） |
| `web/src/presentation/geometry.ts` | CesiumJS に依存しない形状の計算（単体テストあり）。s ごとの点と左向きの法線を作り、断面を掃引する |
| `web/src/presentation/textures.ts` | 実行時に canvas で描く画像（アスファルト・コンクリート・フェンス・広告）。画像ファイルや外部素材は使っていない |
| `web/src/presentation/layer.ts` | CesiumJS の Primitive を作る・消す。オフにすると Primitive とマテリアル（テクスチャ）をすべて破棄する |

- GIS の処理（`gis/`）と Issue #10・#11 の研究コードは変更していない。
- 既存コードの変更は、切り替えの UI（`index.html`・`main.ts`）と、車両の高さの補正（`VehicleAnimation.setGroundLift` と `web/src/vehicle/lift.ts`）だけ。

## 3. 高さの扱い（地形と建物は別の問題）
- **地形の高さ：** 路面・バリア・広告の各頂点で PLATEAU-Terrain の高さを取得し（`sampleTerrainMostDetailed`）、その上に置く。
  - 路面は横に 5 点（2.25 m 間隔）、縦に 2 m 間隔なので、横断勾配にも沿う。地面から 0.10 m 浮かせて、ちらつきを防ぐ。
  - 車両の高さ（PR レビュー後に修正）：仮想路面がある区間（s = 290〜560 m）だけ、車両を同じ 0.10 m 持ち上げて路面に合わせる。区間の外では従来の高さに戻す。
    - 入口と出口では、区間のすぐ外側の 4 m で滑らかに上げ下げする（smoothstep。高さも傾きも途切れない。勾配は最大 3.75 %、高低差は 0.10 m）。区間の中では常に路面の高さなので、路面に埋まらない。
    - 演出がオフのときは補正がなく、従来とまったく同じ高さ。
    - コース上の距離・カメラの追従方法・ミニマップの計算は変えていない（追走・空撮カメラの注視点は、車両の高さに合わせて最大 0.10 m 動く）。
  - バリアの面は地面の下 0.3 m まで伸ばし、斜面で隙間が見えないようにした。
- **建物との水平の干渉：** 自動の判定は実装していない（設定どおり手動で配置）。3D 表示で配置を確認し、下の数値でも確かめた。ただし、この数値は**限られた点でのサンプリングによる確認**で、すべての位置で干渉がないことを証明するものではない。

| 5. 見た目 | 追走（s = 330）、車載風（s = 296）、空撮（s = 420）でオン・オフを比べる | 下の画像。車載風で広告の文字が読める |

- **メモリ：** テクスチャは計算で約 5.6 MB（路面 512×1024、フェンス 256×256、コンクリート 256×64、広告 1,280×160 を 4 枚、RGBA）。頂点データは 1 MB 未満。JS ヒープは 10 回の切り替えの前後で 488 MB → 420 MB で、増え続けてはいない（GC の時期に左右されるので参考値）。GPU のメモリは直接は計測していない。

- **コンソール：** エラーは地理院の空中写真タイルの 404 だけ（範囲外のタイル。この変更の前からある）。

## 5. 制限
- **直線だけ：** 法線は 8 m の向きの窓で求める。90° の角に路面をかけると、内側の帯が折り返して重なる。角の形状は今回は作っていない。
- **配置は手動：** 交差点の位置は、デモコースの区間の境目と 3D 表示から選んだ。別のコースに使うには、新しい設定ファイルが必要。
- **テクスチャ：** Cesium の Image マテリアルはミップマップを作らないので、遠くのアスファルトの粒や縁石の模様が少しちらつく。
- **路面の幅：** 実際の道路の幅とは関係ない仮の値（この区間の実際の道路は、もっと広く見える）。
- **画面の幅：** 幅 800 px 程度の画面では、操作パネルの注意書きが右下の地形・建物の状態表示と少し重なる。
