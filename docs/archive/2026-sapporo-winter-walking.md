# Introduction

## 1. 研究背景

札幌市では、冬季の積雪や路面凍結によって歩行環境が大きく変化する。  
歩行者は、地上歩道だけでなく、地下歩行空間「チ・カ・ホ」、地下街、アーケード、ロードヒーティングが整備された歩道などを組み合わせて移動している。

特に、次のような人にとって冬道の歩きやすさは重要である。

- 革靴やヒールを履く通勤者・就職活動中の学生
- スーツケースや大きな荷物を持つ人
- 冬道に慣れていない観光客・出張者
- 高齢者、車いす利用者、ベビーカー利用者

しかし、どの道にロードヒーティングがあり、積雪時に人々がどの経路へ移動するのかを一体的に確認できる情報は限られている。

## 2. 先行研究

本研究に関連する先行研究として、主に以下が確認されている。

- **工藤ほか（1999）**  
  GISを用いて札幌市のロードヒーティング網の配置と道路投資を評価した。設備配置の評価が中心であり、現在の歩行者経路選択は対象としていない。

- **Muraleetharan et al.（2005）**  
  北12条駅から北海道大学までの代替経路を対象に、冬期路面と信号待ち時間が歩行者の経路選択に与える影響を分析した。ロードヒーティング等によって無雪となる経路が選ばれやすい可能性を示した。

- **Krivorotko et al.（2024）**  
  チ・カ・ホ内部の人流と季節・気温との関係を分析した。地下空間内部の人流を対象としており、同時刻の地上経路やロードヒーティング区間との比較は行っていない。

- **Watanabe and Setoguchi（2024）**  
  札幌市北3条広場「アカプラ」で、積雪範囲、気象条件、歩行・滞留行動の関係を分析した。

- **札幌市（2023）**  
  冬季バリアフリー調査により、ロードヒーティング区間は移動しやすい一方、加熱区間と非加熱区間の境界や段差が障壁になることを示した。

参考文献・引用リストは、研究室ルールに従い、READMEとは別のGitHub IssueでAPA形式を基本として管理する。

## 3. 研究ギャップ

関連する研究は存在するが、本研究の文献調査の範囲では、次の要素を同時に扱った研究は確認できなかった。

1. 札幌都心部の地上歩道・地下歩行空間・アーケード・ロードヒーティングを、一つの歩行ネットワークとして扱うこと
2. 同じ地点・時間帯において、無積雪時と積雪・凍結時の歩行者経路を比較すること
3. 人流データ、気象データ、路面状態、ロードヒーティング区間をGIS上で統合すること
4. 積雪時の経路選択の変化に、地下歩行空間やロードヒーティングがどの程度関与しているかを定量的に評価すること

したがって本研究では、ロードヒーティング地図の作成自体を最終目的とせず、**積雪の有無による歩行者の経路選択の変化と、その変化に地下歩行空間・ロードヒーティングがどの程度関与しているか**を中心に分析する。

## 4. 研究目的

本研究の目的は、次の3点である。

1. 積雪の有無によって、歩行者の経路選択がどのように変化するかを明らかにする。
2. 地下歩行空間やロードヒーティングが、積雪時の経路選択にどの程度関与しているかを分析する。
3. 得られた結果をGIS上で可視化し、冬季に歩きやすい経路を検討する。

## 5. Research Questions

### RQ1

積雪の有無によって、地上・地下・アーケード等の歩行者経路選択はどのように変化するか。

### RQ2

積雪・凍結時には、地下歩行空間を利用する歩行者の割合が増加するか。

### RQ3

積雪・凍結時には、ロードヒーティング区間を含む経路の利用割合が増加するか。

### RQ4

気温、降雪、時間帯、曜日、信号待ちなどを考慮した場合、地下歩行空間やロードヒーティングは経路選択とどの程度関連するか。

## 6. 仮説

- **H1：** 積雪時には、無積雪時より地下経路の選択率が高くなる。
- **H2：** 積雪時には、ロードヒーティング区間を含む経路の選択率が高くなる。
- **H3：** 歩行者は、最短距離より多少長くても、積雪や凍結を避けられる経路を選ぶ。
- **H4：** 地下・屋根・ロードヒーティングによって保護される割合が高い経路ほど、積雪時の利用率が高くなる。

# Methods

## 1. 対象地域

対象は、札幌駅から大通、すすきのにかけての札幌都心部を想定している。

候補地点は以下のとおりである。

- 札幌駅南口周辺
- 大通・チ・カ・ホ出入口周辺
- 狸小路―すすきの周辺
- ホテル・観光施設から地下入口までの地上区間

札幌市全域を網羅するのではなく、地上・地下など複数の経路選択が発生する3～5地点に限定する。

## 2. 歩行ネットワークの構築

QGISを用いて、以下を線データとして整理する。

- 地上歩道
- 地下歩行空間
- 地下街
- アーケード・屋根付き区間
- 建物内接続
- ロードヒーティング区間

ロードヒーティングについては、次を区別して記録する。

- 設備の有無
- 稼働・停止・不明
- 歩道・車道・階段・広場等の区分
- 管理主体
- 調査時点の路面状態
- 確認方法と確認日

## 3. 歩行者観測

独自観測は、チ・カ・ホ公開人流データと結合しやすいように、**15分単位**を基本とする。

同一地点・同一曜日・同一時間帯で、以下の条件を比較する。

| 観測条件 | 初期案 |
|---|---:|
| 無積雪・乾燥日 | 3日以上 |
| 積雪・圧雪日 | 3日以上 |
| 凍結・氷板日 | 可能であれば2日以上 |
| 観測地点 | 3～5地点 |
| 1回の観測 | 15分×4回＝60分 |

記録項目は以下を想定する。

- 経路別・方向別の歩行者数
- 地上・地下・アーケードの選択
- キャリーケース等の客観的に確認できる荷物
- 信号状況
- イベントや工事等の特記事項

外見のみで観光客等の属性を断定しない。

## 4. 路面・気象データ

観測時には、以下を記録または公開データから取得する。

- 気温
- 降雪量
- 積雪深
- 降水量
- 風速
- 路面の乾燥・湿潤
- 新雪・圧雪・シャーベット
- 凍結・氷板
- ロードヒーティングによる融雪状況
- 現地写真

## 5. 使用予定データ

| ファイル | 内容 |
|---|---|
| `network_segments.geojson` | 地上・地下・アーケード等の歩行区間 |
| `verified_heating_segments.geojson` | 確認済みロードヒーティング区間 |
| `surface_observations.csv` | 区間・日時ごとの路面状態 |
| `pedestrian_counts.csv` | 経路別・方向別の15分歩行者数 |
| `weather_joined.csv` | 気温・降雪・積雪・風等の結合データ |
| `route_choice_survey.csv` | 任意アンケートによる経路選択理由 |

## 6. 分析方法

### 経路選択率

```text
経路選択率
= 特定経路を利用した歩行者数 ÷ 比較対象となる全経路の歩行者数
```

無積雪時と積雪・凍結時について、次の利用割合を比較する。

- 地上経路
- 地下経路
- アーケード経路
- ロードヒーティング区間を含む経路

### 経路の保護割合

候補経路ごとに、地下、屋根、ロードヒーティングによって保護されている区間の延長割合を求める。

```text
経路別保護割合
= 保護区間の延長 ÷ 経路全体の延長
```

### 統計分析

必要に応じて、二項ロジットモデル等を検討する。

```text
protected_route_selected
~ snow_or_ice
+ temperature
+ recent_snowfall
+ signal_delay
+ time_of_day
+ weekday_or_holiday
+ event_day
+ luggage
```

本研究は観察研究であるため、ロードヒーティングが経路変更の唯一の原因であると断定せず、他の条件を考慮した上で「関連」や「関与の程度」として評価する。

# 構想発表｜札幌都心部における冬季歩行者の経路選択分析

## 研究テーマ

**札幌都心部における冬季歩行者の経路選択分析**  
**― 積雪の有無と地下歩行空間・ロードヒーティングの関与―**

## 発表原稿

私の研究テーマは、札幌都心部における冬季歩行者の経路選択です。札幌では、積雪や路面凍結によって歩きやすさが大きく変わり、人々はチ・カ・ホやロードヒーティングのある歩道を選んでいると考えられます。

関連する先行研究として、冬期路面と経路選択を扱った研究、チ・カ・ホ内部の人流を分析した研究、ロードヒーティングの配置をGISで評価した研究は確認できました。一方で、これらを札幌駅・大通・すすきの周辺で一体的に扱い、積雪の有無による経路変化と、地下空間やロードヒーティングの関与を同時に分析した研究は、私が調査した範囲では確認できませんでした。

そこで、無積雪時と積雪時に、同じ地点・曜日・時間帯で経路別の歩行者数を観測します。さらに、気象データ、チ・カ・ホの人流、ロードヒーティング区間をGIS上で統合し、積雪時に地下や加熱歩道の選択率がどの程度変化するかを比較します。ただし、地下鉄や商業施設の利用も考えられるため、雪だけが原因とは断定せず、経路選択との関連や関与の程度として評価します。最終的には、冬に歩きやすい経路を地図として可視化します。

---

## 発表時の要点

- 主役はロードヒーティング地図ではなく、**歩行者の経路選択**
- 無積雪時と積雪時を、同じ地点・時間帯で比較
- チ・カ・ホ、地上歩道、ロードヒーティングを一つのネットワークとして分析
- 気象・人流・路面環境をGISで統合
- 「影響」と断定せず、他の条件を考慮して関与・関連を評価

## 想定質問

### Q. ロードヒーティングの位置はどう調べるのか

札幌市への資料照会、公開資料、現地調査、OpenStreetMap等を組み合わせて確認する。設備の有無と、調査日の稼働・路面状態は分けて記録する。

### Q. どこで観測するのか

札幌駅、大通、すすきの周辺のうち、地上・地下など複数の経路へ歩行者が分かれる3～5地点を候補とする。

### Q. 何を比較するのか

同じ地点・曜日・時間帯における、無積雪時と積雪・凍結時の経路別歩行者数を比較する。

### Q. 先行研究との違いは何か

既往研究では、冬期路面と経路選択、地下人流、ロードヒーティング配置が個別に扱われている。本研究では、それらを札幌都心部の同一ネットワーク・同一時間帯で統合して分析する。

---

## 現時点での懸念点・研究上の限界

### チ・カ・ホを選択した理由を人流観測だけで特定できない

積雪時にチ・カ・ホの利用者が増加したとしても、その全員が雪や凍結を避ける目的で地下を選択したとは限らない。

チ・カ・ホを利用する理由には、以下の可能性がある。

- 地下鉄さっぽろ駅・大通駅を利用するため
- 地下街や沿道の商業施設を利用するため
- 地下に直接接続する建物や目的地へ向かうため
- 信号待ちや横断歩道を避けるため
- 寒さ、風、降雪を避けるため
- 単に普段から地下経路を利用しているため

そのため、定点観測や公開人流データだけでは、個々の歩行者の移動目的や経路選択理由を正確に把握することは難しい。

本研究では、積雪時の地下利用者増加をそのまま「雪が原因」と断定せず、**積雪・気温・時間帯・曜日・駅や商業施設の利用など、複数の要因と関連する可能性がある**ものとして扱う。

### 対応方法

- 同一の出発地・目的地に対して、地上と地下の両方を選べる分岐地点を優先して観測する
- 同じ曜日・時間帯で無積雪時と積雪時を比較する
- 地下鉄の利用者が集中する時間帯と、それ以外の時間帯を分けて分析する
- 商業施設の営業時間、休日、イベント、工事等を記録する
- 必要に応じて短時間の任意アンケートを実施し、経路選択理由を確認する
- 結果は「因果関係」ではなく、地下・ロードヒーティング利用と積雪条件との「関連」または「関与の程度」として解釈する

### 今後検討すること

- [ ] 観測時間帯ごとの利用目的の違いを整理する
