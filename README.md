# Introduction

## 1. 研究背景

札幌市では、冬季の積雪や路面凍結によって歩行環境が大きく変化する。  
歩行者は、地上歩道だけでなく、地下歩行空間「チ・カ・ホ」、地下街、アーケード、ロードヒーティングが整備された歩道などを組み合わせて移動している。

特に、次のような人にとって冬道の歩きやすさは重要である。

- 革靴やヒールを履く通勤者・就職活動中の学生
- スーツケースや大きな荷物を持つ人
- 冬道に慣れていない観光客・出張者
- 高齢者、車いす利用者、ベビーカー利用者

しかし、どの道にロードヒーティングがあり、積雪時に人々がどの経路へ移動するのかを一体的に確認できる情報は限られている。

## 2. 先行研究

本研究に関連する先行研究として、主に以下が確認されている。

- **工藤ほか（1999）**  
  GISを用いて札幌市のロードヒーティング網の配置と道路投資を評価した。設備配置の評価が中心であり、現在の歩行者経路選択は対象としていない。

- **Muraleetharan et al.（2005）**  
  北12条駅から北海道大学までの代替経路を対象に、冬期路面と信号待ち時間が歩行者の経路選択に与える影響を分析した。ロードヒーティング等によって無雪となる経路が選ばれやすい可能性を示した。

- **Krivorotko et al.（2024）**  
  チ・カ・ホ内部の人流と季節・気温との関係を分析した。地下空間内部の人流を対象としており、同時刻の地上経路やロードヒーティング区間との比較は行っていない。

- **Watanabe and Setoguchi（2024）**  
  札幌市北3条広場「アカプラ」で、積雪範囲、気象条件、歩行・滞留行動の関係を分析した。

- **札幌市（2023）**  
  冬季バリアフリー調査により、ロードヒーティング区間は移動しやすい一方、加熱区間と非加熱区間の境界や段差が障壁になることを示した。

参考文献・引用リストは、研究室ルールに従い、READMEとは別のGitHub IssueでAPA形式を基本として管理する。

## 3. 研究ギャップ

関連する研究は存在するが、本研究の文献調査の範囲では、次の要素を同時に扱った研究は確認できなかった。

1. 札幌都心部の地上歩道・地下歩行空間・アーケード・ロードヒーティングを、一つの歩行ネットワークとして扱うこと
2. 同じ地点・時間帯において、無積雪時と積雪・凍結時の歩行者経路を比較すること
3. 人流データ、気象データ、路面状態、ロードヒーティング区間をGIS上で統合すること
4. 積雪時の経路選択の変化に、地下歩行空間やロードヒーティングがどの程度関与しているかを定量的に評価すること

したがって本研究では、ロードヒーティング地図の作成自体を最終目的とせず、**積雪の有無による歩行者の経路選択の変化と、その変化に地下歩行空間・ロードヒーティングがどの程度関与しているか**を中心に分析する。

## 4. 研究目的

本研究の目的は、次の3点である。

1. 積雪の有無によって、歩行者の経路選択がどのように変化するかを明らかにする。
2. 地下歩行空間やロードヒーティングが、積雪時の経路選択にどの程度関与しているかを分析する。
3. 得られた結果をGIS上で可視化し、冬季に歩きやすい経路を検討する。

## 5. Research Questions

### RQ1

積雪の有無によって、地上・地下・アーケード等の歩行者経路選択はどのように変化するか。

### RQ2

積雪・凍結時には、地下歩行空間を利用する歩行者の割合が増加するか。

### RQ3

積雪・凍結時には、ロードヒーティング区間を含む経路の利用割合が増加するか。

### RQ4

気温、降雪、時間帯、曜日、信号待ちなどを考慮した場合、地下歩行空間やロードヒーティングは経路選択とどの程度関連するか。

## 6. 仮説

- **H1：** 積雪時には、無積雪時より地下経路の選択率が高くなる。
- **H2：** 積雪時には、ロードヒーティング区間を含む経路の選択率が高くなる。
- **H3：** 歩行者は、最短距離より多少長くても、積雪や凍結を避けられる経路を選ぶ。
- **H4：** 地下・屋根・ロードヒーティングによって保護される割合が高い経路ほど、積雪時の利用率が高くなる。

# Methods

## 1. 対象地域

対象は、札幌駅から大通、すすきのにかけての札幌都心部を想定している。

候補地点は以下のとおりである。

- 札幌駅南口周辺
- 大通・チ・カ・ホ出入口周辺
- 狸小路―すすきの周辺
- ホテル・観光施設から地下入口までの地上区間

札幌市全域を網羅するのではなく、地上・地下など複数の経路選択が発生する3～5地点に限定する。

## 2. 歩行ネットワークの構築

QGISを用いて、以下を線データとして整理する。

- 地上歩道
- 地下歩行空間
- 地下街
- アーケード・屋根付き区間
- 建物内接続
- ロードヒーティング区間

ロードヒーティングについては、次を区別して記録する。

- 設備の有無
- 稼働・停止・不明
- 歩道・車道・階段・広場等の区分
- 管理主体
- 調査時点の路面状態
- 確認方法と確認日

## 3. 歩行者観測

独自観測は、チ・カ・ホ公開人流データと結合しやすいように、**15分単位**を基本とする。

同一地点・同一曜日・同一時間帯で、以下の条件を比較する。

| 観測条件 | 初期案 |
|---|---:|
| 無積雪・乾燥日 | 3日以上 |
| 積雪・圧雪日 | 3日以上 |
| 凍結・氷板日 | 可能であれば2日以上 |
| 観測地点 | 3～5地点 |
| 1回の観測 | 15分×4回＝60分 |

記録項目は以下を想定する。

- 経路別・方向別の歩行者数
- 地上・地下・アーケードの選択
- キャリーケース等の客観的に確認できる荷物
- 信号状況
- イベントや工事等の特記事項

外見のみで観光客等の属性を断定しない。

## 4. 路面・気象データ

観測時には、以下を記録または公開データから取得する。

- 気温
- 降雪量
- 積雪深
- 降水量
- 風速
- 路面の乾燥・湿潤
- 新雪・圧雪・シャーベット
- 凍結・氷板
- ロードヒーティングによる融雪状況
- 現地写真

## 5. 使用予定データ

| ファイル | 内容 |
|---|---|
| `network_segments.geojson` | 地上・地下・アーケード等の歩行区間 |
| `verified_heating_segments.geojson` | 確認済みロードヒーティング区間 |
| `surface_observations.csv` | 区間・日時ごとの路面状態 |
| `pedestrian_counts.csv` | 経路別・方向別の15分歩行者数 |
| `weather_joined.csv` | 気温・降雪・積雪・風等の結合データ |
| `route_choice_survey.csv` | 任意アンケートによる経路選択理由 |

## 6. 分析方法

### 経路選択率

```text
経路選択率
= 特定経路を利用した歩行者数 ÷ 比較対象となる全経路の歩行者数
```

無積雪時と積雪・凍結時について、次の利用割合を比較する。

- 地上経路
- 地下経路
- アーケード経路
- ロードヒーティング区間を含む経路

### 経路の保護割合

候補経路ごとに、地下、屋根、ロードヒーティングによって保護されている区間の延長割合を求める。

```text
経路別保護割合
= 保護区間の延長 ÷ 経路全体の延長
```

### 統計分析

必要に応じて、二項ロジットモデル等を検討する。

```text
protected_route_selected
~ snow_or_ice
+ temperature
+ recent_snowfall
+ signal_delay
+ time_of_day
+ weekday_or_holiday
+ event_day
+ luggage
```

本研究は観察研究であるため、ロードヒーティングが経路変更の唯一の原因であると断定せず、他の条件を考慮した上で「関連」や「関与の程度」として評価する。

# Results

調査・分析後に、以下を掲載する。

- 無積雪時と積雪時の経路選択率
- 地下経路の利用割合の変化
- ロードヒーティング区間を含む経路の利用割合の変化
- 路面・気象条件との関係
- QGISによる人流・歩行環境マップ
- 分析結果の図表

---

# Discussion

分析後に、以下の観点から考察する。

- 地下歩行空間とロードヒーティングの役割
- 最短経路と歩きやすい経路の関係
- ロードヒーティング区間の連続性と境界の問題
- 観測地点・時間帯による違い
- 札幌市の冬季歩行環境への示唆
- 調査方法とデータの限界

---

# Conclusion

最終的には、積雪の有無による歩行者の経路選択の変化と、地下歩行空間・ロードヒーティングの関与について結論をまとめる。

また、冬季に歩きやすい経路をGIS上で可視化し、札幌市の歩行環境評価や情報提供に活用できる可能性を検討する。
