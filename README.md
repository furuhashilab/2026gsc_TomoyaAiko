# 札幌都心部における冬季歩行ネットワークの分析
### ― 雪の有無による歩行者経路選択と地下歩行空間・ロードヒーティングのカバー率評価 ―

## 概要

本研究では、札幌市都心部を対象として、**雪の有無によって歩行者の経路選択がどのように変化するのか**を分析する。

特に、

- 地下歩行空間（チ・カ・ホ）
- ロードヒーティング
- アーケード

などの冬季歩行環境が、歩行者の移動をどの程度支えているのかをGISを用いて可視化・分析する。

---

# 背景

札幌市では、積雪や路面凍結によって冬季の歩行環境が大きく変化する。

そのため歩行者は、

- 地下歩行空間（チ・カ・ホ）
- ロードヒーティング
- アーケード

などを利用しながら移動している。

先行研究では、

- 冬期路面が歩行者の経路選択へ与える影響
- 地下歩行空間（チ・カ・ホ）の人流分析
- ロードヒーティングの配置・整備評価
- 冬季歩行環境や転倒リスク

などは個別に研究されている。

しかし、本研究で実施した文献調査の範囲では、

**地下歩行空間・ロードヒーティング・地上歩道を一つの歩行ネットワークとして統合し、雪の有無による歩行者の経路選択の変化を分析した研究は確認できなかった。**

また、

- 人流データ
- GIS
- 気象データ
- ロードヒーティング
- 地下歩行空間

を統合し、冬季歩行ネットワークを定量的に評価した研究も確認できなかった。

---

# 研究目的

本研究の目的は次の2点である。

1. 積雪の有無によって歩行者の経路選択がどのように変化するかを明らかにする。

2. 地下歩行空間・ロードヒーティングが冬季歩行ネットワークをどの程度カバーしているかを評価する。

---

# 研究の新規性

本研究の新規性は次の3点である。

① 地下歩行空間・ロードヒーティング・地上歩道を統合した歩行ネットワークを構築すること

② 雪の有無による歩行者の経路選択の変化を実測データから分析すること

③ 人流データ・気象データ・GISデータを統合し、「実効カバー率」という指標を用いて冬季歩行環境を評価すること

---

# Research Questions

### RQ1

雪の有無によって歩行者の経路選択は変化するか。

### RQ2

積雪時には地下歩行空間・ロードヒーティングの利用割合は増加するか。

### RQ3

地下歩行空間・ロードヒーティングは歩行ネットワークをどの程度カバーしているか。

### RQ4

実際の歩行者の利用状況を考慮した場合、実効カバー率はどのように変化するか。

# 研究方法

## ① 歩行ネットワークの構築

GISを用いて

- 地上歩道
- 地下歩行空間
- アーケード
- ロードヒーティング

を線データとして整備する。

## ② 人流観測

同一地点・同一曜日・同一時間帯で、

- 無積雪日
- 積雪日
- 凍結日

の歩行者数を15分単位で観測する。

## ③ 路面状態調査

各歩道区間について、

- 積雪
- 圧雪
- 凍結
- ロードヒーティング

を記録する。

## ④ データ統合

以下のデータをGIS上で統合する。

- 歩行ネットワーク
- 人流データ
- 気象データ
- 路面状態

## ⑤ GIS解析

以下を算出する。

- 経路選択率
- 物理ネットワークカバー率
- 経路別カバー率
- 人流加重実効カバー率
